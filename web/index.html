振幅劇場

グローバー探索可視化工房 — 目印をおよそ √N 回の照会で照らし出す、量子の振幅増幅

グローバー探索とは

グローバー探索は、1996 年に Lov Grover が考案した量子探索アルゴリズムです。N 件の候補の中から「目印付き」の 1 件を見つけるとき、古典計算機は片っ端から調べるしかなく、平均で N/2 回、最悪で N 回の照会が必要です。量子計算機はすべての候補を重ね合わせで同時に持ち、目印の振幅だけを干渉で少しずつ育てることで、およそ √N 回の照会で目印を見つけます。100 万件なら、100 万回ではなく約 785 回——これが「二次加速」です。

仕組みは 2 つの操作の繰り返しだけです。オラクルが目印候補の振幅の符号を反転し、拡散が全振幅を平均のまわりで反転する。すると目印の振幅だけが一回りごとに育っていきます。ただし回しすぎると振幅は逆に縮み始める——やめどきまで含めて数学が決めている、という美しいアルゴリズムです。

ここでは何を可視化しているか

この劇場では、量子状態を振幅の棒グラフとしてそのまま観察できます。舞台に並ぶのは N 本の棒——各候補の符号付き振幅です。

  • オラクル(反転) — 金色の目印の棒が、軸の下へ突き落とされる瞬間
  • 拡散(増幅) — 全部の棒が破線の平均線のまわりで反転し、目印だけが大きく跳ね上がる瞬間
  • 成功確率曲線 — 測定したとき目印が出る確率 sin²((2t+1)θ) の理論曲線。最適回数 t* を過ぎると確率が下がる「回りすぎ」も、そのまま曲線に現れます

棒をクリックして目印を付け替え、半歩ずつ踏んで、増幅の幾何を確かめてください。

なお、これは古典計算機による厳密シミュレーションです。量子コンピュータの動作を数学どおりに再現していますが、シミュレーション自体は N に比例した手間をかけており、量子加速そのものをここで体験しているわけではありません(それができるなら量子計算機は要りません)。
